# 黒子筆で図面を処理する

塗る前の図面（`data/raw/` の下）は、Read・Bash・Grep などで直接開かない。フックで止まる。必ず MCP ツール `mask_drawing` を通す。

## 手順

1. 対象の図面を決める
   - パスを言われたらそのまま使う
   - 言われなければ、ユーザーにファイル名を聞く。`data/raw/` の中を一覧しようとしない（フックで止まる）
   - 図枠の下辺ぜんぶが表題欄の図面（河川境界確定図など）なら、`config` に `bottom_strip` を渡す
2. `mask_drawing(path, config)` を呼ぶ。OCR は1枚30〜40秒かかる（2回目以降はキャッシュで1秒未満）
3. 結果を次の形で要約する。地番の文字列は出してよい。氏名は結果に含まれないので、推測して書かない
   - 塗った図面：`masked_path`（ワールドファイルもコピー済みなら、その旨）
   - 地番：`chiban` の件数。`status` が `split` のもの（氏名と1つの枠から切り出した地番）は件数を添える
   - 塗った数：`masks.total` と `masks.by_status` の内訳
   - 人が見るべきもの：
     - `unpaired`（地番とペアにならない文字を塗ったもの）
     - `mixed_masked`（氏名と地番が1つの枠で、分けられずに全体を塗ったもの。地番が消えている可能性）
     - `in_title_block`（表題欄の文字を塗ったもの。図名など消したくないものがないか）
     - `uncertain`（数字主体だが地番と判定できず、塗らずに残したもの）
     - `masked_below` が `false` の地番（下に氏名が見つからなかった。塗り漏れの可能性）
4. 最後に「確認画面で、塗り漏れと塗りすぎがないか見てください」と伝え、`open_review(masked_path)` を呼んでブラウザで確認画面を開く
   - 確認画面は人の道具。URL は返ってこないし、Claude は確認画面に接続しない（curl などはフックで止まる）
   - 返り値の `confirmed` が `false` なら、人が「確定して塗り直す」を押すまで、塗った図面を AI に渡す作業に進まない

## 「幾何補正して」と頼まれたとき（④、実験中）

地番だけで図面の位置合わせをし、ワールドファイル（.tfw）を作る。Claude は生の図面を見ない。

1. 上の手順 1〜4 で塗り、確認画面を開く
2. 「確認画面で確定したら教えてください」と伝えて、**人の返事を待つ**。返事が来たら `list_masked()` で `confirmed` が `true` になったことを確かめる。`false` なら先に進まない
3. 公図の GeoJSON（`data/ref/<図面>.geojson`）があることを確かめる。なければ、公図データが必要だと伝えて止まる
4. サブエージェント `matcher` に図面名を渡して照合を頼む
5. matcher の報告をそのまま伝える：使ったペア数、残差（m）、読み替えた地番、外したペア、向きの確認。出力した `.tfw` のパス（`data/masked/<図面>.tfw`）を示す
6. 残差が大きい、ペアが少ない、向きが怪しいときは、GIS で重ねて確かめるよう伝える

## してはいけないこと

- `data/raw/` のファイルを Read・Bash・Grep で開く、一覧する
- 結果にない氏名を推測して書く
- 確認前の図面を「安全です」と言い切る（エンジンには既知の制約がある。README「既知の制約」）
