# 黒子筆で図面を処理する

塗る前の図面（`data/raw/` の下）は、Read・Bash・Grep などで直接開かない。フックで止まる。必ず MCP ツール `mask_drawing` を通す。

## 手順

1. 対象の図面を決める
   - パスを言われたらそのまま使う
   - 言われなければ、ユーザーにファイル名を聞く。`data/raw/` の中を一覧しようとしない（フックで止まる）
   - 図枠の下辺ぜんぶが表題欄の図面（河川境界確定図など）なら、`config` に `bottom_strip` を渡す
2. `mask_drawing(path, config)` を呼ぶ。OCR は1枚30〜40秒かかる（2回目以降はキャッシュで1秒未満）
3. 結果を下の「塗ったあとの報告」の形で伝える。氏名は結果に含まれないので、推測して書かない
4. `open_review(masked_path)` を呼んでブラウザで確認画面を開く
   - 確認画面は人の道具。URL は返ってこないし、Claude は確認画面に接続しない（curl などはフックで止まる）
   - 返り値の `confirmed` が `false` なら、人が「確定して塗り直す」を押すまで、塗った図面を AI に渡す作業に進まない

## 報告の形（短く。画面で読める長さにする）

前置き、手順の説明、見出し、表は書かない。下の形だけを書く。0件の項目は行ごと省く。

### 塗ったあとの報告

```
塗りました：<masked_path>（.tfw もコピー済み）
地番 <件数>件：<先頭10件をカンマ区切り> ほか<残り>件（全件は <result_path>）
塗り <masks.total>か所：氏名 <auto>／ペアなし <unpaired>／表題欄 <in_title_block>／枠ごと <mixed_masked>／分割 <split>
残した表題欄の情報 <title_meta の件数>件
人が見るところ：地番と判定できない数字 <uncertain の件数>件、下に氏名が見つからない地番 <masked_below が false の件数>件
確認画面で、塗り漏れと塗りすぎがないか見てください。
```

頼まれたのが地番の一覧でも、同じ形で先頭10件と件数だけを書く。全件を書くのは、全件を見たいと言われたときだけ。

### 止められたときの報告

フックに止められたら、次の2行だけを書いて止まる。自分から `mask_drawing` に進まない（図面を塗るかどうかは人が決める）。

```
止まりました：<止めた規則>。塗る前の図面は、Claude が直接開けません。
黒子筆で塗ってから扱えます。塗りますか？
```

## 「幾何補正して」と頼まれたとき（④、実験中）

地番だけで図面の位置合わせをし、ワールドファイル（.tfw）を作る。Claude は生の図面を見ない。

1. まず `list_masked()` を呼び、その図面がすでに塗ってあって `confirmed` が `true` なら、**塗り直さずに** 3 へ進む。確定済みの図面に `mask_drawing` を呼ぶと、人が確定した結果が自動の塗りで上書きされて消える
2. まだ塗っていない、または確定していなければ、上の手順 1〜4 で塗り、確認画面を開く。「確認画面で確定したら教えてください」と伝えて、**人の返事を待つ**。返事が来たら `list_masked()` で `confirmed` が `true` になったことを確かめる。`false` なら先に進まない
3. 公図の GeoJSON（`data/ref/<図面>.geojson`）があることを確かめる。なければ、公図データが必要だと伝えて止まる
4. サブエージェント `matcher` に図面名を渡して照合を頼む
5. matcher の報告の数字をそのまま使い、下の形で伝える。`.tfw` や `georef.json` を自分で読み直さない。前置きや見出しは書かない

```
<確定済みなら「確定済みなので、塗り直さずに照合しました」>
ワールドファイルを作りました：data/masked/<図面>.tfw
ペア <pairs_used>/<pairs_found>組、残差 RMS <m>（地番の文字と筆の重心のずれで、位置の誤差ではありません）
向き：<正しい／怪しい>（上下を反転すると <mirrored_pairs_used>組しか合わない）
読み替え <件数>件、外したペア <件数>件
GIS で公図と重ねて確かめてください。
```

図郭線をダミーの正解データから取ったときは、最後に「図郭線はダミーの正解データから取りました」の1行を足す。

## してはいけないこと

- `data/raw/` のファイルを Read・Bash・Grep で開く、一覧する
- 結果にない氏名を推測して書く
- 確認前の図面を「安全です」と言い切る（エンジンには既知の制約がある。README「既知の制約」）
