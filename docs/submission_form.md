## 開発中に一番詰まった場面（3,000字）

①何を作ろうとしていましたか
スキャンした測量図面から、地番の真下にある地権者の氏名だけを塗りつぶすエンジンです。氏名は読まず、OCRが検出した文字の枠のうち「数字が主体でないもの」を塗る、という方針にしていました。地番は数字だけなので残り、氏名は漢字なので塗られる。文字の種類だけで判定し、氏名の文字列は保存しない設計です。

②Claude にどのように指示しましたか
設計担当のClaude（Fable）が設計書に「OCRの枠を、(a)地番、(b)数字が主体だが地番でない、(c)それ以外、に分け、(c)を塗る」と書き、実装担当のClaude Code（Opus）に実装させました。精度はダミー図面5枚で測り、1つ直すごとに accuracy_log に1行記録する運用です。

③何が起きましたか
数字の上では氏名カバー率が99%を超えたのに、できあがった図面を私が目で見ると、引き出し線が密集した場所で「420-10」の下の氏名（架空）が丸ごと残っていました。関所として一番あってはいけない失敗です。

④期待していた結果と何が違いましたか
氏名は漢字だから必ず「(c)それ以外」に入って塗られる、と期待していました。実際には、OCRがその氏名と右隣の地番「273-10」を横並びの1つの枠として読んでいました。漢字3文字＋数字5文字で「数字が主体」と判定され、地番として保護する側に倒れていたのです。「数字なら個人情報ではない」という前提が、枠の切り方ひとつで崩れていました。

⑤どのように対処しましたか
原因の特定はOpusに「この場所の氏名が残っている。原因を突き止めてから直すこと」とだけ伝え、Opusが該当の枠を調べて横並びの混在だと報告しました。対策はFableが判断しました。数字と非数字が混在する枠は、文字数の比率で仮の分割位置を置き、その近くでインク（黒画素）の谷を探して分割し、数字側が地番なら残して非数字側を塗る。谷が見つからなければ枠全体を塗る（地番は失うが、個人情報を残すよりよい）。Opusは実装の途中で「文字数の比率で分けると姓と名の隙間に分割線が入って『茂』が地番側に残る」ことに気づき、□を数字2文字分の幅として数える、文字より広い隙間だけを谷とする、という補正を足しました。この件で学んだのは、精度の数字だけでは関所の穴は見つからないこと、現場の人間が図面を目で見る工程を開発の中に入れておく必要があることです。確認画面を「人の道具」として設計に残した理由でもあります。

## Claude を使った感想と改善してほしい点（3,000字）

①日本語や日本の業務で使う立場から気づいた欠点と利点
利点は、日本語の設計書と現場の言葉がそのまま通じたことです。「地番」「筆」「引き出し線」「図郭」「公図」「表題欄」といった測量の用語を説明なしで理解し、「地番は筆界線に重ねない。入らなければ筆の長軸に合わせて回す。それでも入らなければ引き出し線」という私の配置ルールを、ダミー図面の生成コードにそのまま落としました。報告が日本語で、しかも「できたこと」「指示から補った点」「判断がほしいこと」に分かれていたので、夜に指示を出して昼間に動かし、帰宅後に判断だけする働き方ができました。欠点は、長い作業の途中で報告が突然英語に切り替わったことが一度あったこと（CLAUDE.md に「報告は日本語」と書いて解決）と、日本の個人情報の扱いの「発注者ごとに考えが異なる」という実務の感覚までは持っていないので、そこは人が決めて書く必要があったことです。

②他の AI ツールと比べて劣る点と優れる点
設計の相談には ChatGPT も並行して使いました。優れる点は、Claude Code がフック・MCP・スキル・サブエージェントを同じ場所で組み合わせられることで、「Claudeが生データを見ずに仕事をする」という構成そのものが、他のツールでは組めませんでした。実装担当のClaude Code が、判断に迷うと自分で決めずに questions.md に書いて止まる、という運用を守れたことも大きい。劣る点は、画面（確認画面）を自分で見られないため、UIのバグは人が触って見つける必要があったことです。

③一つだけ直せるとしたら何か
Claude Code の permissions.deny で、Bash コマンドに対しても「このフォルダのファイルに触るコマンドは止める」というパスの条件を書けるようにしてほしいです。今回はフックを自分で書いて、grep のグロブや python -c の文字列連結まで判定しましたが、文字列の判定なので誤検知も抜け道も残ります。本体がファイルパスの単位で止めてくれれば、黒子筆の関所は設定ファイルの数行になり、フックを書けない小さな測量会社や自治体でも、同じ守りを自分の図面に使えるようになります。
